# @erpax/commerce

erpax **commerce** — sequence **4·8 (flow)**: transactional flow — parties, orders, payments, subscriptions, inventory.

Built from [`src/commerce`](https://github.com/erpax/erpax/tree/main/src/commerce) by `packages/build.mjs`; the runtime closure is bundled, bare imports stay external (computed into dependencies), and the closure ratchet (`erpax.closureCeiling`) fails the build closed if entanglement grows.
