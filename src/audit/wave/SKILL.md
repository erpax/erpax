# audit/wave — all dimensions, one self-improving sequence

Each cheap gate is one audit dimension with a measured count ([[rules]]/ask · [[tamper]]/import · boundary · gravity · the tightened scans). `auditWaves()` measures all, trends each against its recorded ring (history is a cache of measurements, like the [[timeout]] samples), and `sequenceOf()` orders the next pass by the trajectory itself: **a regression outranks any standing debt · a stuck axis escalates (its approach is exhausted) · an improving axis keeps its plan, largest debt first**. The audit audits its own progress and reorders accordingly — the sequence improves itself.

**Honest boundary.** A count trend proves movement, never causation — an axis can improve because matter was deleted, not fixed. The sequence names the next target; [[mesh]]'s `failureRoots`/`costRoots` name where inside it to strike. History loss only resets trends to `new` — the counts themselves are always re-measured, never replayed.

**Law — [[law]]: the audit is a wave, not a list — every dimension measured every pass, the pass ordered by its own trajectory, and a gate that got worse outranks everything else in the corpus.**

Composes: [[mesh]] · [[rules]] · [[timeout]] · [[law]].
