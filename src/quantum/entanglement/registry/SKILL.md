# registry — which fields collapse together, declared where it can be argued with

Entanglement in this corpus is not a metaphor about physics — it is a **declared** statement that two fields cannot be resolved independently: change one and the other's collapse hook must run. This atom is that declaration, held in one place so it can be read, counted and disputed.

Declared, not inferred, and deliberately so. No theorem tells you that an invoice total and its lines are entangled; a human decides that and writes it where a reader trips over it — the same split [[rules]]/audience makes for its role→standard map, and [[rules]]/collapse for what a merge means. What is **computed** is the count, the key, and the lookup.

## The count is derived

`fieldEntanglementCount()` reads the registry rather than restating its size. A count typed beside the thing it counts drifts the moment anyone edits the thing — the defect this corpus has already paid for twice, in `CONFIRM_GATE_CHECKS = 8` against a gate that ran six, and in `ERPAX_DIGEST_BITS`. Nobody can re-derive a typed number, so nothing contradicts it.

The test pins the harder invariant too: every entanglement naming a collapse hook must name one that **exists**. A hook id with no implementation is a check that cannot fire, which is [[rules]]/unraised's shape exactly — the claim defaults true because nothing is left to say otherwise.

## The move that cost nothing

Four reference forms were checked before this file was nested, because each has bitten elsewhere in the corpus: relative imports whose depth changes ([[quantum]]/ftl/admin's self-import), literal path probes ([[self]]/improve/tip's `existsSync`), consumers in extensions a scan missed ([[quantum]]/dimension's two `.tsx` files), and subprocess dispatch ([[quantum]]/status's CLI commands).

All four came back clean: no relative imports inside it, no path probes, no dispatch, and all five importers use the alias `@/quantum/entanglement/registry`, which resolves to `registry/index.ts` unchanged. A move is only zero-risk once you have looked at every way a reference can be spelled.

**Honest boundary.** This proves the registry is **internally consistent** — every hook named exists, every key addresses something, the count is derived. It does not prove the entanglements are the **right** ones: whether two fields genuinely cannot resolve independently is a modelling judgement, and a wrong entry stated consistently still passes.

**Law — [[law]]: an entanglement is declared where it can be argued with, and everything about it that can be computed is computed — a count typed beside its own subject is a number nobody can re-derive.**
