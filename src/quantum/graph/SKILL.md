# quantum/graph — the graph as entanglement

The quantum facet of [[graph]]: an edge is an **entangled pair**, and [[entanglement]] is symmetric, so a coherent corpus reciprocates every edge in both directions — the "no gap in entanglement in any direction" law, directed-link entropy → 0. `isReciprocal` tests it; `reciprocate` is the symmetric closure; `entangled` is the connected component of a node once reciprocated.
