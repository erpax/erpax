# quantum/ftl/book — the answer was already folded

[[quantum]]/ftl asks whether the advantage **holds**. This asks a question and answers it from what is already sealed: `chatLocal` resolves against the book, `searchSealed` and `sealScore` rank the corpus, `researcher` reads it.

They lived in the ftl hub — a predicate and a search engine in one scroll, which is exactly the shape [[rules]]/concentration names. The hub now offers every one of these names and holds none of them.

**Honest boundary.** A sealed answer proves the question was ASKED before and the fold kept it; it does not prove the answer is right. What is in the book is what someone put there — the seal covers provenance, never truth.
