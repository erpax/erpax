# journal/entries/hooks — debits equal credits, refused at the write

`validateBalancedEntry` is the fundamental law of double entry enforced where the entry is saved.
Checking it in a report instead means the unbalanced entry already exists and every statement built
on it is wrong until someone runs that report.
