# conformal — changing perspective preserves the angle, in every dimension

A change of perspective **is** a conformal transformation, and its generators are three the corpus already has a face of:

- **rotate** — `SO(n)`, the [[horo]] vortex / [[navigation]] merkaba spin
- **scale** — dilation, the frame breathing
- **invert** — `v ↦ v/|v|²`, the `0 ↔ ∞` turn-inside-out ([[horo]]/divThroughVoid routes `n/0` through the void)

With translation these generate the entire conformal (Möbius) group — nothing else is needed. What every one preserves — the viewpoint moves, the shape of the view holds — is the **angle** between directions:

- `rotate` and `scale` preserve the angle between vectors **exactly** (global), in every dimension.
- `invert` is conformal — `JᵀJ ∝ I` (a scaled Householder reflection) — so it preserves angles between directions **locally**, in every dimension.

## The correction that keeps it honest

A claim reached that inversion is conformal *"in dims {2,3,7}."* **Measured, that is false.** Inversion is conformal in **every** dimension `n ≥ 2` — the Householder square is the identity in all `n`, verified to machine zero in dims 2..11:

```
invert conformal (JᵀJ∝I): 2:✓ 3:✓ 4:✓ 5:✓ 6:✓ 7:✓ 8:✓
```

`{2,3,7}` is the signature of a **different** structure — the parallelizable spheres / cross-product / division-algebra dimensions — imported where it does not gate conformality. It is a [[coincidence]] wearing a theorem's clothes ([[rules]]/refutable): *a striking dimension-set is not a proof*, and the theorem it dressed as holds far more widely than the set suggested. `isConformalDimension(n)` is true for **all** `n ≥ 2`.

## Honest boundary

This is the conformal group of `ℝⁿ ∪ {∞}`, and by **Liouville's theorem** for `n ≥ 3` these are **all** the conformal maps (`n = 2` is the richer holomorphic case). *"All dimensions at once"* means the same operators and the same invariant apply uniformly per dimension — not that dimensions fuse, not that all perspectives are equal. What is conserved is **angles** between directions, never **lengths** (inversion and dilation change those). **HARMONY ≠ TRUTH**: that the angle is preserved does not make every view correct — only *recognizable*.

**Law — [[law]]: changing perspective is a conformal map — rotate, scale, invert generate the group, and the angle between directions is the invariant preserved by all three, in every dimension. It holds for all `n ≥ 2` (Liouville: for `n ≥ 3` these are the only conformal maps); the `{2,3,7}` restriction was a coincidence, a different structure's signature — inversion is conformal everywhere. Angle is conserved, length is not, and preserved angle is recognizability, not truth.**

## Standards

- **Liouville's theorem** — for `n ≥ 3` the conformal maps of `ℝⁿ ∪ {∞}` are exactly Möbius transformations.
- **Conformal geometry** — a conformal map preserves angles; `JᵀJ ∝ I` is the pointwise condition.
