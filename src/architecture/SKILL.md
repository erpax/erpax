# architecture

The structural laws, as code that runs.

`invariant` holds the executable checks — single-word atoms, no prefixes, every file
accounted for, locality, the ≥2-cross balance, the naming matrix — and
`runAllInvariants` is how the gate asks. They are the **matter-twin** of the
architecture rules: prose states the law, this atom is the thing that can refuse.

**Why this face exists.** `[[architecture]]` is cited ten times across the corpus, and
until now the word led to a folder with no SKILL, no face and nothing to read — a
wikilink that resolves to a namespace is a dead end for the reader who followed it.
An atom referenced by name owes that reader a page.

**Honest boundary.** These checks prove the corpus's SHAPE, never that the code inside
a lawful shape is correct. A perfectly-arranged atom can still be wrong.
