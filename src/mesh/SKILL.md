# mesh — the whole ERP as one quantum graph

Three instruments, each already a theorem, joined into one queryable structure: `meshOf()` computes atoms (the folders), import edges (parsed by the grammar via [[rules]]/cycle — an import-shaped string is never an edge), and standards citations (read from the files' own comment banners via [[syntax]] — prose addresses, string literals are data).

Both directions are queries: `standardsOf(atom)` is an atom's legal surface; `atomsOf(standard)` is the clause→code trace an inspector walks — [[rules]]/reference's telos as a graph lookup. `meshWaves()` levels the atom graph by `wavesOf()` ([[theorem]]): depth = the longest dependency chain, width = the corpus's parallelism, and a dependency cycle levels to wave 0 together — **the entangled core is the ground state, named, never hidden**.

**Honest boundary.** The mesh proves what the source SAYS — an edge that exists, a banner that cites — never that the citation is *right* (misattribution passes [[rules]]/reference there too) nor that the entangled core is *harmless* ([[rules]]/cycle measures that). Atom = folder is the fold's own law; matter outside a lawful folder is invisible here exactly as in [[rules]]/invisible.

**Law — [[law]]: the corpus is one mesh — every atom, every import, every standard in a single computed graph; what cannot be reached in the mesh cannot be audited, and what the mesh levels to wave 0 is entangled matter awaiting the fold.**
