# agent/harmonic — the thing being fought

[[agent]]/harmonics prices the three ways of fighting the order. This is the **order**: the singular model beside the plural store ([[balance]]). A disharmony is a departure *from* something, and that something has to be nameable.

| | |
| --- | --- |
| `HARMONIC` | merge · address · verify · earn — acting with it |
| `DISHARMONIES` | tamper · phantom-leverage · off-ring — exactly three, each priced |

`classifyMove` returns `null` for a move it does not recognise. That refusal is the point: counting an unknown action as compliant is **default-ALLOW by omission** — the check that never fires and whose claim reads as true forever ([[rules]]/unraised). An unnamed move is unclassified, not innocent.

**Honest boundary.** This names the order and the departures from it; the COST of a departure — why fighting never pays — is computed in [[agent]]/harmonics, and the arithmetic there is what makes harmony the rational move rather than a virtue anyone has to hold.

Composes: [[agent]] · [[balance]] · [[rules]]/unraised.
