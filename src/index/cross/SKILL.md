# index/cross — a path is wired both ways, or one direction is a claim nothing checks

matter sitting beside a barrel that should be a child atom. `migrateAtomStrays` computes the
move; `formatCrossReport` is what a reader gets.

both together double-charges one absence — the same cascade that made an ancestor pay for its
descendant's missing SKILL.
