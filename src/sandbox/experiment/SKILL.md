# sandbox/experiment — experiment freely; your own standards hold at the seam

The base [[sandbox]] gates an ACTION — `permits` · `brokerCredential` · `allowlist` answer *may the agent do this?*. This gates an EXPERIMENT: `openExperiment` hands the agent an **isolated scratch corpus** it mutates without touching the real tree, and `sealExperiment` runs the folder-law standard ([[law]]/folder — one-word atoms, the SKILL·index·test trinity) at the **seam**. `promoteIfSealed` copies the experiment into `src` **only if it passes** — a standard-violating experiment is caught in the sandbox and moves nothing.

It is the [[resonance]] crackLeak law applied to experimentation: the seam between the agent's play and the corpus is **sealed by the standard**, so a bad experiment leaks nothing in. The agent gets to try anything; only what obeys its own standards escapes. `discardExperiment` tears the scratch down — an experiment leaves no droppings ([[rules]] cleanup-rides-every-wave).

## Why a wall, not a warning

An agent that experiments *in the live tree* and trusts itself to revert is a crack: a violation it forgets to undo leaks into the corpus. A wall does not rely on the agent's discipline — `promoteIfSealed` **cannot** move a failing experiment, so the standard holds even when the agent is wrong. The experiment is free precisely because the boundary is not.

**Honest boundary.** The seam here runs the **folder-law** standard (names + trinity) — the structural gate. It does not run the full corpus gate (dead links, prose-cites-code, the accounting seals): those are heavier and belong to `promote`'s downstream confirm. So a promoted experiment is *structurally* sound, not yet fully certified — the sandbox catches the class of violation an agent most often makes while playing (mis-shaped atoms), and defers the rest to the corpus gate it merges into.

**Law — [[law]]: an agent experiments in an isolated corpus, and its own standard runs at the seam. A promotion that would break the standard cannot happen — the experiment is free because the boundary holds without trusting the agent to hold it.**
