# book/compute — the corpus read as a book of books, computed rather than written

Every atom is a page, every partition a volume. `computeBookIndex` derives the volume rows,
`pathExplain` says what a path means segment by segment, and `renderBookIndexMarkdown` emits
the index as a document.

Nothing here is authored: the volumes, their page counts and their harmony are read off the
live matrix, so the book cannot disagree with the corpus it indexes — the same rule the drift
law applies to any number stated in prose.
