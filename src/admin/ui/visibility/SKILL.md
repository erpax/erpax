# admin/ui/visibility — a collection appears in the panel because a rule says so, not because it exists

231 collections rendered flat is a list nobody navigates. Visibility decides what this user's panel
offers, computed from the collection's own metadata rather than from a maintained allow-list — so a
collection added tomorrow is placed by the same rule as every other.
