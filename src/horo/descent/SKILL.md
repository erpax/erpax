# descent — horo position 7 (the wave returns)

`descent` is the **turn** of the [[horo]] ring — digit `7`, where the doubling [[coil]] folds back from the peak (`8 → 16 ⇒ 7`) and the **return** arc begins (`7·5·9`). The built flow now moves outward: inventory *shipped*, value *given*, the entry *posted out*.
