# agents/mcp/tool/frontier — the corpus's own next move, on the public surface

[[self]]/sufficient's `nextDirection` could always **order** a frontier and never **generate** one:
every intent had to be typed by a person into [[think]]'s store. So the corpus could rank its own
work and not find it — which is the gap between *automated* and *self-sufficient*.

`internalLeads` closes it. Four measurements become intents:

| source | the lead | cost |
| --- | --- | --- |
| `guardians` | a red axis — `assertRulesHold` | one full gate pass |
| `unreached` | an atom nothing reaches | one full scan |
| `crosses` | a proven cross not yet drawn | one scan per law |
| `boundary` | an `unreachable` probe — an unasked question, not a failure | the network |

None runs unless asked for, and the default is the cheapest one, because every source is a corpus
scan and a tool that always pays for all four is a tool nobody calls.

## Crossing the leads is where the confidence comes from

The cross keys on the **target** — an axis name, an atom path — never on the sentence, because a
guardian's evidence and a cross's evidence never share text. A target that **two independent sources
both name** is `corroborated`, and outranks anything one source found alone: the same argument
`unearnedCopies` makes for `copy × unfolded`. `carried` orders the sources by [[conjecture]]'s
DIRECTIONAL containment — a source whose targets sit inside another's is downstream of it — and
`orthogonal` names the sources that meet nothing, which are the only ones whose signal nothing else
would produce.

The intersection and containment come from [[conjecture]] rather than being re-derived here
([[rules]]/copy).

## The wording carries the rank, and four keywords were matching letters

An intent is ranked by the standing queue, so how a lead is **worded** decides its priority — and
the queue was matching substrings:

| keyword | also matched | effect |
| --- | --- | --- |
| `red\b` | shared · measured · required · covered · considered | rank **5**, *regression*, on ordinary prose |
| `gate` | aggregate · delegate · mitigate · investigate | rank **3**, *blocks-everything* |
| `dead` | deadline · deadlock | rank 2 |
| `unfold` | — missed `un-folded`, which is how this corpus writes it | rank **0** for its own debt |

This tree exports `aggregateCorpusEntropy` and writes "measured" in nearly every sentence it
produces, so the top of the queue was close to flat: almost anything could rank as the most urgent
thing there is. All four are anchored now and pinned by tests. That is [[rules]]/probe's law arriving
at the ranker — a filter that selects by name cannot see what it does not name, and catches instead
whatever happens to contain the letters.

**Every emitted intent is asserted to rank above 0**, and that invariant immediately caught one of
mine: once the false `red` match was gone, the boundary lead matched no keyword at all and was
unrankable, so unactionable. It is worded as a `gap` now, which is what an unasked question is.

## Honest boundary

A lead is a **candidate**, never a verdict: a red axis may be red for a reason someone already
decided to accept, and an unreached atom may be a public face ([[rules]]/unfolded's own boundary).
Corroboration raises confidence, it does not confer correctness — two measurements can agree and
both be pointing at something that should stay.

It is self-sufficient in the sense that matters — no network and no human-typed intent — but not
omniscient: it sees exactly the four sources wired here, so a defect no gate measures is invisible to
it, which is [[rules]]/domain restated one surface over.

**Law — [[law]]: a corpus that can only rank a frontier it was handed is not self-sufficient. Generate
the frontier from measurement, cross the sources so agreement is visible, and word each lead so the
queue can actually rank it.**

## The source that could not fire

`SOURCES` declared four and `liveSources` wired three. `crosses` was accepted by the enum, validated by
zod, and contributed nothing — [[rules]]/unraised's defect inside the tool that reports the frontier.

Wired, it answers **zero, and that is correct**: of the ten pairs among the five measured laws, the two
with a non-empty intersection are already drawn in prose and the two undrawn ones measure 0 shared.

`populations` exists because a guardian yields a COUNT, and a count names no atom, so no red axis could
corroborate anything. It supplies the axis's violating members as ATOM paths via `atomOfFile` from
[[mesh]], so a law's finding and an unreached atom finally meet at one address. Both sources read the
same five scans behind one lazy promise.

The crossing itself, the namespaces it refuses to compare and the lift that separates agreement from base
rate are argued where the transform lives: [[self]]/sufficient.
