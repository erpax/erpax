# agents/mcp/tool/millennium — the Clay statements, held against public data from the chat

| tool | what it answers |
| --- | --- |
| `erpax.millennium.data` | every dataset witness of [[millennium]]/data, run now — witnesses, worst deviation, bound, receipt over the dataset bytes — plus the refusals with their reasons; `unreachable` is a list, never a pass |
| `erpax.millennium.perspectives` | every problem crossed with the perspectives the corpus reads it from — lens atoms, referrers with their standards, tested-or-refused — with `coverageGaps` asserted empty; no network |

Both answer `corpusSolves: false` in every reply, because the register does and an MCP reply must not
be read as softer than the register.

**Honest boundary.** A witness that holds is consistency on the sample the public API returns without
a credential; a failing one would be a named counterexample on public data. Neither is a proof, and
the tool says so in the field it puts first.

**Law — [[law]]: a Clay statement is tested on public data or refused by name, from the chat as from
the lane, and the reply leads with the refusal the register already makes.**

Composes: [[millennium]]/data · [[mcp]] · [[law]].
