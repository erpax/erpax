# pathophysiology

Changes in the normal mechanical, physical, and biochemical functions that are associated with this activity or condition.

Entangled with — [[associated]]

Attested in schema.org — associatedPathophysiology · pathophysiology

**Law — [[law]]: pathophysiology is defined only as a deviation from a baseline of normal function — without the healthy reference there is no disorder to describe, so it is always stated relative to the norm it departs from.**
