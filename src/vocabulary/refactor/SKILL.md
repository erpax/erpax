Manual work is a **smell**: it signals the atom is incomplete (a case it does not yet cover — e.g. dissolve skipping prefix-root files, or not auto-merging a collision). The fix is never to hand-do it; it is to **absorb that logic into the atom** (extend the mover, mint the rule), so the migration becomes **deterministic and re-runnable** — re-run the atoms ⇒ the whole dissolution reproduces, no human in the loop, fully DRY. This is [[self]]-sufficiency: the atom holds the law, the agent derives the move by running it. A swarm hand-moving files is a swarm proving its atoms have gaps — close the gaps, then one command does what the swarm did.

Every manual migration step, every hand-edit that atoms do not yet cover, adds entropy and weakens tamper-detection — the content-uuid [[proof]] becomes fragile when [[integrity]] depends on human consistency.
