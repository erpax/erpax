# standards/document — the standards seed as nested pages

The standards seed (`src/standards/seed.ts`) is one generated list: each standard, its family, and
the modules that cite it. It already seeds the Payload `standards` collection and the gates read
it as code. This atom gives it its third reader — a person or an agent — as documents.

- `standardRows(entries)` — the register page, one page per family listing its standards, and one
  page per standard: what it is, how many modules cite it, and a table of those modules with the
  clause each one pins.
- `standardPath` · `standardSlug` — a standard lives at `standards/<family>/<id>`.
- `standardMarkdown` — one standard as a document.

The pages are derived, never typed, so a page cannot name a module the seed does not record.

```
tsx src/standards/document/index.ts
tsx src/seed/content/load/index.ts --url <origin> --seed src/standards/document/seed.generated.json
```

Generated on 2026-11-13: 263 standards became 282 pages.

**Honest boundary.** A page says a standard is CITED and where; it says nothing about whether the
citing code conforms — that is [[proof]]/replaceable's question. The seed is regenerated by its
emitter and the pages are regenerated from the seed, so a loaded page is as fresh as the last load,
not as the tree. The generated page seed is not tracked; the standards seed it is derived from is.

**Law — [[law]]: one list of standards, read three ways — by the collection as rows, by the gates
as code, and by a reader as pages — and none of the three is typed twice.**

Composes: [[standards]] · [[seed]]/content · [[proof]]/replaceable · [[law]].
