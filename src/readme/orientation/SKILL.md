# readme/orientation — a front page orients, or it is a census

erpax's README projects **measurements**: 3,191 atoms, 37,824 bonds, entropy tables, dependency dumps. A reader learns the corpus's size and nothing about what to do.

Measured 2026-08-01: **63%**, missing `inversion · open-problems · limits`.

## The bar is derived, not asserted

Each criterion cites the feature it came from on the sibling portal — a page solving the same problem for the same corpus family:

| criterion | derived from |
| --- | --- |
| identity | *"Double Torus — 740 proven theorems you can check yourself"* opens the page |
| first-command | `npm install` · `npm run check:types` are named |
| census | 740 theorems · 30 pages · 54 sections published |
| sequence | a "Sequence Discovery Realised" section |
| inversion | "Angle · Polarity" |
| quantum-usable | `npm run quantum:qpu-cpu` — an invocation, not a mention |
| open-problems | "Clay Millennium Problems", carrying `claySolvedByThisFold=0` |
| limits | explicit Limitations · Reproducibility · "NOT a QPU" |

Deriving the bar from a **working example** is the point: the comparison is checkable, and anyone may argue with the source rather than with an opinion. It is a front page's own [[rules]]/audience problem — a page addressed to someone who already knows is addressed to nobody — and [[constitution]] Law 5: a result served with no recompute path a newcomer can run is offered for belief.

## The instrument caught itself first

Two of the eight predicates were anchored on whitespace and so missed commands written in **backticks** — the normal case in a README. The suite failed on its own fixture, not on the page, and the score only became trustworthy after the fix. Distrust the measurement before the tree.

## Honest boundary

This reads the **text**. A keyword match is a *proxy* for orientation, not orientation itself: a page can satisfy all eight and still read badly, and only a human decides that. The eight are **declared** in the open so the bar can be argued with — a ninth thing a reader needs is invisible to it by construction. `assertOrients` is a ratchet run **upward**: a floor, not a ceiling, because this is a quantity that should rise.

**Law — [[law]]: a front page says what the thing IS, gives a first command, publishes its numbers, states its open problems, and names its limits — or it is a census wearing a welcome.**
